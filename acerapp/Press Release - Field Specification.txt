Press Release|Dynamic Form Field Specification|
Purpose: This document defines every field in the Press Release entry form. All sections marked [STATIC] are hardcoded in the HTML output. All sections marked [DYNAMIC] are filled in by the user through the form interface. The final output is a rendered HTML press release that matches the CRISIL format.

5. KEY RATING DRIVERS — STRENGTHS [DYNAMIC BLOCKS]
Each strength is an expandable/collapsible block. Click "+ Add Strength" to append a new one.
Each Strength Block Fields:
#
	Field Name
	Field Type
	Placeholder
	Notes
	5.1
	strength_title
	Text Input
	e.g. Strong managerial and financial support from Tata Sons
	Displayed as bold subheading
	5.2
	strength_body
	Rich Text Editor
	Bullet points or paragraphs
	Supports bullet lists, bold, italic. Covers: facts/reasons, criticality, ACER expectations
	Controls: [+ Add Strength] / [✕ Remove] / [↑↓ Reorder] (drag handles).
Minimum: 1 strength. No maximum.

OUTPUT FORMAT
* Final output: Single-page HTML file styled to match ACER/CRISIL press release format
* The HTML output should be self-contained (inline CSS)A "Preview" button should render the live HTML output alongside the form
* A "Download HTML" button exports the final file
* Optional: "Save Draft" stores the form state as JSON in localStorage
